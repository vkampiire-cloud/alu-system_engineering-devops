# ALU System Engineering & DevOps

Repository containing system engineering, networking, DevOps, and infrastructure projects.

## Modules

- `ssh`: SSH key authentication, client configuration, and server administration.
- `web_server`: Nginx web server installation, configuration, and custom pages.
- `load_balancer`: HAProxy load balancer setup, round-robin algorithms, and HTTP header tracking.
- `firewall`: UFW (Uncomplicated Firewall) incoming and outgoing traffic filtering.
- `web_stack_debugging_0`: Docker container debugging and Apache web server troubleshooting.
- `web_stack_debugging_1`: Nginx port configuration troubleshooting and service restoration.
- `web_stack_debugging_2`: Running processes as non-root users and running Nginx as the `nginx` user.
- `web_stack_debugging_3`: Troubleshooting Apache 500 error using strace and automating the fix with Puppet.
- `web_stack_debugging_4`: Benchmarking with ApacheBench and increasing Nginx file descriptor limits with Puppet.
