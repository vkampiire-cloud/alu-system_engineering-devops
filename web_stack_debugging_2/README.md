# Web Stack Debugging #2

This directory contains solutions for the **Web stack debugging #2** project in the ALX/ALU DevOps curriculum.

## Tasks

| File | Description |
| --- | --- |
| `0-iamsomeoneelse` | Bash script that accepts a username as an argument and executes `whoami` under that user using `su`. |
| `1-run_nginx_as_nginx` | Bash script that configures Nginx to run as the `nginx` user and listen on port 8080. |
